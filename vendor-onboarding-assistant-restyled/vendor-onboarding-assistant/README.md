# AI Vendor Onboarding & Approval Assistant

Automates the first pass of enterprise vendor onboarding: deterministic
document checks (missing / expired files, coverage thresholds) plus a
grounded RAG pass against your own policy PDFs, an audit trail, a
correction-notice email flow, and a WCAG-friendly review dashboard with
voice dictation and read-aloud.

```
├── backend/
│   ├── main.py           FastAPI app: endpoints, deterministic rules, audit log
│   └── rag_service.py    ChromaDB indexing + LLM gateway calls (with local fallbacks)
├── frontend/
│   └── src/App.jsx       React dashboard (Setup tab + 3-panel Review tab)
├── generate_test_pdfs.py Builds synthetic policy + vendor PDFs into test_docs/
├── requirements.txt
└── .env.example
```

## How it works

- **Deterministic checks never touch the LLM.** Missing documents, expired
  dates, and the insurance-coverage minimum are plain Python comparisons in
  `main.py`, so they're reproducible and auditable.
- **Policy compliance is grounded RAG.** Reference PDFs you upload (or the
  generated samples) are chunked and embedded into ChromaDB; each vendor
  case retrieves the matching clauses and the model is asked to cite them
  side-by-side with the extracted document text.
- **Nothing is required to run the demo.** If `GENAILAB_API_KEY` isn't set,
  `rag_service.py` transparently swaps in local fallbacks — hashed lexical
  embeddings, regex field extraction, a template summary — and reports which
  mode is active back to the UI (`ai_mode` / `extraction_mode` /
  `gateway_configured`) so nothing is silently faked. Same for email: without
  `RESEND_API_KEY`, "Send Correction Notice" returns a preview instead of
  dispatching.

## Prerequisites

- Python 3.10+
- Node.js 18+

## Setup (under 5 minutes)

### 1. Backend

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # optional — see "Configuration" below
python generate_test_pdfs.py     # writes test_docs/ with sample PDFs

cd backend
uvicorn main:app --reload --port 8000
```

Visit `http://localhost:8000/docs` to confirm it's up.

### 2. Frontend

In a second terminal:

```bash
cd frontend
npm install
cp .env.example .env             # defaults to http://localhost:8000, edit if needed
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Configuration

All variables are optional — see `.env.example` (backend, project root or
`backend/.env`) and `frontend/.env.example`.

| Variable | Used for | Default |
|---|---|---|
| `GENAILAB_API_KEY` | OpenAI-compatible gateway key for embeddings, extraction, RAG summaries, Whisper | *(unset → local fallback mode)* |
| `GENAILAB_BASE_URL` | Gateway base URL | — |
| `RESEND_API_KEY` | Live vendor emails via Resend | *(unset → preview-only)* |
| `RESEND_FROM` | Sender for correction/approval emails | `Vendor Onboarding <onboarding@resend.dev>` |
| `MIN_INSURANCE_COVERAGE` | Deterministic threshold check | `1000000` |
| `EXPIRY_WARNING_DAYS` | Flag documents expiring soon | `30` |
| `CORS_ORIGINS` | Comma-separated origins allowed to call the API | `*` |
| `VITE_API_BASE_URL` (frontend) | Backend URL the UI calls | `http://localhost:8000` |

Model IDs (`azure/genailab-maas-whisper`, `azure/genailab-maas-text-embedding-3-large`,
`azure/genailab-maas-gpt-4o-mini`, `genailab-maas-gpt-4o`) are set as constants
at the top of `backend/rag_service.py`.

## Walking through the three demo paths

1. Open the app → **📁 Setup Reference Rules** tab → **Index sample policies**
   (or drag in your own policy PDFs and click index). This loads the
   `Procurement_Policy.pdf` / `Onboarding_Checklist.pdf` generated by
   `generate_test_pdfs.py`.
2. Switch to **📑 Vendor Review Dashboard** → use a **Load Sample Preset**
   button in Panel 1 to try each path against the same backend logic:

   | Preset | What happens |
   |---|---|
   | `Vendor_Happy_Path` | All documents valid, $1.5M cover → all checks pass → **Ready for approval** |
   | `Vendor_Expired_Tax` | Tax certificate expired, bank proof missing → **Resubmission required** → draft + send a correction notice |
   | `Vendor_Low_Insurance` | Valid documents, but $500k cover vs. the $1.0M policy minimum → **Risk / exception found** → use the 🎤 dictation button to enter a reviewer rationale, then sign off |

3. Panel 2 shows the extracted key-values plus the retrieved policy clause
   next to the vendor's text for every RAG-checked field. Panel 3 has the
   audit log download, the `🔊` read-aloud summary, and the `☀️/🌙`
   high-contrast toggle in the top bar.

You can also skip the presets and drag your own PDFs into either dropzone —
the pipeline is the same either way.

## Troubleshooting

- **UI shows "Can't reach the backend"** — confirm `uvicorn` is running on
  the port in `VITE_API_BASE_URL` and that `CORS_ORIGINS` includes your
  frontend origin (default already allows `*`).
- **Presets list is empty** — run `python generate_test_pdfs.py` from the
  project root first; `main.py` reads presets from `test_docs/`.
- **Chroma / audit data got messy** — everything lives under `data/`
  (gitignored); delete it and restart the backend to reset.
